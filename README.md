# student_performance_system
🎓 Student Exam Performance System
Advanced Analytics & Prediction Platform for Student Academic Success
A web-based application that leverages machine learning to predict and analyze student exam performance across Math, Reading, and Writing subjects.

✨ Features
📊 Performance Indicators
Real-time tracking of student exam performance metrics and analytics, including:
Overall Score
Performance Level (e.g., Average, Proficient, Advanced)
Average Score
Performance Status
🧠 AI Predictions
Machine learning-powered exam score predictions across three subjects:
Math Score — with percentile ranking
Reading Score — with percentile ranking
Writing Score — with percentile ranking
💡 Smart Recommendations
Personalized improvement suggestions based on individual performance data.
🖥️ How It Works
Enter Student Information via the Performance Prediction form:
Gender
Race / Ethnicity
Parental Level of Education
Lunch Type
Test Preparation Course status
Click "Predict Performance" to run the ML model.
View Results including:
Predicted subject scores (Math, Reading, Writing)
Percentile rankings per subject
Performance Summary:
Total Score
Average Score
Highest & Lowest Scores
Performance Grade (e.g., C – Average)
